# Memory

Notes the agent keeps between sessions: the state of your search, decisions you
made and why, lessons from interviews and rejections. One fact per file, with a
one-line index in `MEMORY.md`.

Claude Code keeps its own memory per project; this folder is for what you want
versioned with your profile (and, for example, synced to a claude.ai project so
a chat has the same context).

Examples of what belongs here:

- `status.md` — open applications and where each stands
- `strategy.md` — what you are looking for this month and why it changed
- `feedback-salary.md` — "a range below the floor is not an automatic no; name the gap"
- `lesson-agencies.md` — what worked in letters to agencies
